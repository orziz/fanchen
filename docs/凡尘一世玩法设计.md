# 凡尘立道录 · 凡尘一世玩法设计

> 本文取代挂机式的旧玩法（2026-09 重新设计）。题材与世界规则仍以 [修真题材长期总纲](./修真题材长期总纲.md) 为准；本文只定玩家每一步在做什么、为什么要做、做了会怎样。数值为初值，以模拟与试玩调整。

## 1. 一句话

你是青禾镇的寒门少年，寿元有限。**时间只在你做事时流动**：每件事耗几天、换来什么、冒什么险都摆在明处。在寿尽之前攒底子、求功法、找灵地，一境一境往上走——前期的志向是拜入玉阙行院。

## 2. 要解决的四个问题

| 问题 | 做法 |
|---|---|
| 不知道该干嘛 | 志向链（长线）+ 当前一步（要务卡）+ 此地可做与本旬机缘（眼前） |
| 决定不重要 | 取消挂机；时间是有限的本钱，每件事都有取舍；机缘过期不候；失败有真代价 |
| 系统多而浅 | 收拢为五类动词：修行、营生、历练、人情、赶路；撤掉挂机打算、倍速、货路、拍卖、营生书（产业移到中期） |
| 没手感全是数字 | 事件卷轴：文字 + 选择 + 明示把握（几成）+ 掷定结果；多日行动在场景里快进日夜；突破有仪式 |

## 3. 资源（少而清楚）

- **年岁 / 寿元**：开局 16 岁；凡胎寿元 60，练力 70，感气 90，炼气 120，筑基 200。寿尽则一生结算。
- **气血与伤势**：伤 0–3 级；每级降气血上限一成半、修行效率两成、检定一点。歇息慢慢好，草药与医馆立刻好。
- **灵石**：每月初付口粮与落脚钱（村 2、镇 4、城 8）；付不起就挨饿带伤。
- **修为**：本境进度，满了才能冲关；冲关成功清零进入下一境。
- **体魄 / 悟性 / 魅力**：三项检定属性；**声望**与各**门路好感**。

## 4. 时间

- 一年 12 月、一月 30 日、每月分上中下旬；开局在第一年三月。季节影响可遇的事（春耕、夏汛、秋收、冬雪）。
- 做事耗 1–30 日；赶路按路段耗日（平路 1 日，山路险地 2 日）。
- 每旬初，各地按地盘安危、商气、季节与所投门路刷新**本旬机缘**（1–3 件，过期作废）；界面上这一栏叫“本旬消息”。

## 5. 五类动词

- **修行**：练体（凡胎主路）、静坐 / 闭关（可选 3 / 10 / 30 日，灵气越足越快；没有心法时感气进展极慢）、研读功法、冲关。
- **营生**：打零工（镇上，稳而少）、门路差事（投势后才有）、收购与悬赏类机缘、卖掉采来的东西。
- **历练**：进山 / 探林（按险度抽野外事件：采药、遇兽、奇遇、迷路、遇伤者）、秘境。
- **人情**：拜访此地熟人（好感、求教、送礼、切磋），茶馆打听（揭示别处的机缘）。
- **赶路**：在山河图上择地前往，按路段耗日，途中可能遇事。

## 6. 事件卷轴

- 每个事件：一段文字 + 2–3 个选择。选择可能要花灵石、耗日、需要境界或物品，或是一次检定。
- 检定：把握 = 0.5 + (属性 − 难度) × 0.1，夹在一成到九成半，**点之前就写明几成**。
- 力战类选择进入场景战斗（可自动、可亲手出招）；输了不死：带伤、丢部分灵石与所得。

## 7. 修行与冲关

- 凡胎 → 练力：练体为主；冲关不限地点。
- 练力 → 感气：需要一门心法（如《养气入门诀》），静坐为主；冲关须在灵气 34 以上之地。
- 冲关把握 = 底数 + 灵气 + 悟性 + 丹药 + 伤势修正，点之前写明；失败：伤 +1、修为折三成、耗 10 日，可再试。

## 8. 志向（前期）

1. 攒下第一笔盘缠 → 2. 练出一身力气（练力）→ 3. 求得一门心法 → 4. 感气入门 → 5. 求一份引荐（行院执事好感、声望或推荐信）→ 6. 通过入门试炼 → 7. 拜入玉阙行院。之后转为炼气、筑基等长线目标。

## 9. 寿尽与轮回

寿元尽时一生结算（境界、名望、事迹），可再入轮回：新一世按上一世最高境界带一点传承（悟性与起步物件）。

## 10. 界面

- 顶栏：日期（第几年 · 季 · 月旬）与天气；不再有倍速。
- 左栏人物卡：境界与修为、年岁与寿元、气血与伤势、三项属性、装备。
- 右栏：志向卡（当前一步与去哪里做）、此地机缘与熟人、最近经历。
- 底栏：此地可做的事，每件标明耗日与大致所得；点了先选时长或方式，再执行。
- 书册保留：人物、行囊、山河、市集（只剩买卖）、门路、人情、纪事。

## 11. 存档

新玩法换了时间与数值结构，旧档不再读取：原档另存为封存备份，不删除；读到旧档时标题页提示重开一世。

## 12. 实现与验证

### 12.1 代码落点

- 规则：`src/systems/life/`——`time.ts`（按日推进、月初生计、旬首刷新、寿尽）、`activities.ts`（此地可做的事与赶路、拜访、接机缘）、`runner.ts`（一件事拆成若干步，遇事停下等玩家）、`events.ts` 与 `dynamicEvents.ts`（事件卷轴、冲关、拜访、茶馆、秘境）、`hooks.ts`（破境、冲关受挫、拜师、入门等落实）、`cultivation.ts`（修为速度、冲关条件与把握、寿元）、`goals.ts`（志向）、`opportunities.ts`（机缘）、`legacy.ts`（结算与传承）。
- 配置：`src/config/calendar.ts`、`src/config/life.ts`（生计、伤势、检定公式）、`src/config/lifeEvents/`（事件文字与选择）、`src/config/opportunities.ts`（机缘模板）；境界表 `RANKS` 的 `need` 改为“在上一境里要攒满的修为”，并加了 `lifespan`。
- 世界：`systems/world.ts` 只剩路网与 `advanceWorldDay()`；NPC、势力、地盘与商况每日推演一次，NPC 满 360 日长一岁。
- 界面：`ActionDock`（此地可做、时长选择、交战指令）、`EventScroll`（事件卷轴）、`ObjectiveCard`（志向与刚做完的事）、`LocalPanel`（本旬消息与熟人）、`LifeEndDialog`（一世结算）；场景在过日子时快进日夜。

### 12.2 与初稿的差异

- 歇息每满五日伤好一级；冲关受挫另需养伤十日，这十日不算歇息。
- 有心法时静坐速度 = 1.4 ×（1 + 心法修行加成 × 5）×（0.6 + 灵气 / 50）×（1 − 伤势 × 0.2）×（1 + 悟性 × 0.02）；没有心法时凡胎 0.6、入境后 0.25。
- 练体在凡胎时每日修为 1.2（有练体门路之地 × 1.25），入境后 0.35；体魄每日长 0.05 ÷（1 + 境界 × 0.5）。
- 冲关底数：入练力 0.7、入感气 0.55、入炼气 0.45；养元散、明神丹、灵泉丸分别托高相应关口。
- 玉阙入门试炼三关：体魄检定（难度 6）、悟性检定（难度 5）、与外院师兄过招（险三）；未过可下一旬再来。

### 12.3 数值模拟

`src/testing/lifeBot.ts` 是照着志向走的模拟玩家：遇事选把握最大的一项，交战交给自动出招，伤重先歇。十局从开局到拜入玉阙行院的结果：

| 项 | 结果 |
|---|---|
| 用时 | 276–368 个游戏日（约一年），入门时 16–17 岁 |
| 决定次数 | 93–144 次（挑一件事或在卷轴里选一项都算一次） |
| 卡死 | 无 |
| 各志向大致节点 | 盘缠第 1–10 日，练力约第 75 日，心法约第 110 日，感气约第 230–290 日 |

- 前期寿元压力还很轻（入门时离凡胎寿元尚远），前期的取舍主要来自时间、生计与机缘期限；寿元的压迫感要到中后期境界需求变大后才显出来，中期设计时需再核。
- `src/systems/life/life.test.ts` 里保留一条同样的回归：模拟玩家须在 2500 步内拜入玉阙且不卡死。
