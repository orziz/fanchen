# 首屏界面说明

> 当前界面为网页游戏化重构后的深墨水墨舞台，架构与演出细节见 [网页游戏重构说明](./网页游戏重构说明.md)，视觉细则见 [visual-design-spec.md](./visual-design-spec.md)。

## 产品目标

- 只有一套游戏画面：场景铺满全屏，不维护界面模式或第二套壳层。
- 首屏优先回答三个问题：当前处境是什么、眼前应做什么、从哪里执行。
- 长内容进入书册浮层；书册打开时遮住场景，关上即回到场景，不做可拖拽的浮窗。

## 信息层级

1. 顶栏：名号与境界、灵石与声望、日历（第几年 · 季 · 月旬）与天气、书册入口、存档与设置。
2. 志向卡（右上）：眼下这一步的志向与去哪里做，下面记着刚做完的那件事。
3. 此地（右中）：本旬消息（即各地机缘，带期限与所得）与此地熟人（拜访耗一日）。
4. 场景（中央）：当前地点的山水与主角；过日子时日夜快进，遇事时展开事件卷轴，战斗在这里演出。
5. 人物卡（左侧）：境界与修为、年岁与寿元、气血与伤势、体魄 / 悟性 / 魅力、装备与门路。
6. 纪事（右下）：经历与传闻两栏。
7. 行动坞（底部）：此地可做的事，每件标明耗日；有多个时长的先选时长；交战时换成战斗指令。没有挂机与倍速。

## 交互原则

- 强制剧情使用阻断式遮罩；对话期间世界暂停，打开时焦点落在第一个选项上并被限制在遮罩内，关闭后焦点还原。
- 做不了的事与选不了的选项仍然可见，悬停或点击时说明原因（修为未满、灵气太薄、灵石不够、交情还浅……），不静默失效。
- 所有行动统一经过系统层（`systems/life/`）执行，组件不直接修改资源；正在做事、看卷轴或交战时不能另起新事。
- 志向卡按志向链显示当前一步；交战时换成交战提示，一世尽了换成结算。
- 快捷键：书册 C / B / M / T / F / P / J，Esc 关闭书册；事件卷轴里数字键选选项，回车或空格看完结果。

## 视觉与无障碍

- 场景承担环境识别与氛围，操作内容保持高对比与紧凑排版。
- 交互控件提供统一的 `:focus-visible` 轮廓；图标按钮带读屏文字。
- 设置里的“减少动效”与系统 `prefers-reduced-motion` 都会停掉动画与屏震。
- 整屏使用 `100dvh` 等比缩放，避免移动浏览器地址栏导致裁切；手机横屏可玩，窄竖屏显示横置提示。
