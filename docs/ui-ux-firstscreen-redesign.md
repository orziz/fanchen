# 首屏界面说明

## 产品目标

- 唯一运行界面为 `components/v1`，不再维护界面模式或第二套壳层。
- 首屏优先回答三个问题：当前处境是什么、眼前应做什么、从哪里执行。
- 长内容进入主工作区或工具导轨，不以浮动窗口遮挡核心操作。

## 信息层级

1. 顶部状态栏：角色、资源、时间、速度、存档和三个工具入口。
2. 当前要务：持续显示指引、位置风险、修为门槛及唯一主行动。
3. 主工作区：一次只挂载当前系统面板，地图占满可用舞台。
4. 角色侧栏：桌面端提供角色与随身信息，窄屏并入上下文面板。
5. 底部操作坞：系统导航、手动动作、自动策略与当前位置。

## 交互原则

- 强制剧情使用阻断式对话框；对话期间世界暂停，焦点被限制在对话框内。
- 未开放的导航仍可获得键盘焦点，并通过标题和读屏文本说明原因。
- 手动操作统一经过系统层校验，不允许组件直接修改资源或绕过教程限制。
- 当前要务按教程、剧情、战斗、旅程、低状态、冲关、势力与经济的顺序决策。
- 桌面端工具以右侧导轨显示；小于 960px 时使用同一组件形成全屏工具抽屉。
- 手机视口保留纪事、人物簿、策略盘、存档和全部主导航入口，主要点击目标不小于 40 至 44px。

## 视觉与无障碍

- 山水实景只承担当前要务的环境识别，操作内容保持高对比和紧凑排版。
- 卡片圆角不超过 8px，交互控件提供统一 `:focus-visible` 轮廓。
- 强调色兼顾浅色背景对比；系统尊重 `prefers-reduced-motion`。
- 固定壳层使用 `100dvh`、安全区内边距和内部滚动，避免移动浏览器地址栏导致裁切。
