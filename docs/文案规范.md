# 凡尘立道录 · 文案规范

> 约束游戏里所有给玩家看的文字：人物说话、事件、机缘、地点与物品描述、纪事与提示。目标只有一个——读起来像人写的，像这个世界里的人在说话，而不是一份说明书或一段 AI 生成的套话。
> 与 [project-rules.md](./project-rules.md) 的“游戏内文案规则”并行生效：那边管“能写什么”，这里管“怎么写”。

## 1. 总原则

- **写看得见的东西。** 写人、写物、写动作、写地方的样子与声音，不写概括和评价。
  - ✗ 真正的门路，不在明面上。
  - ✓ 卖豆腐的刘婶压低声音：“真要找活，去码头问老孙，他那儿缺扛包的。”
- **叙述不讲机制。** 功能、数值、条件写在标签、提示和得失里；叙述、描述、台词里不写“适合”“擅长”“提升”“触发”“资源”“稀有”“低阶”“顶级”。
  - ✗ 冰脉环绕的高峰，适合闭关，也容易遭遇争夺寒魄精华的强敌。
  - ✓ 山顶的冰一年到头不化，夜里能听见冰层底下有水在走。半山腰几间石屋封着门，门前的脚印早叫雪埋了。
- **结尾停在事上。** 不用感慨、金句或总结收尾（“旧事随风而去”“心里清静了许多”“又近了一步”）。话说完就停。

## 2. 人物说话

- 按身份说话：掌柜精明、老汉絮叨、猎户粗直、差役打官腔、道人故作高深、同龄人随便。同一段里两个人的口气不能一样。
- 说话会省略、会打岔、会答非所问，不会把道理讲全，也不会替玩家总结“你应该怎么做”。
- 口头的称呼要具体：“后生”“小哥”“这位兄弟”“周掌柜”“韩三叔”，不叫“修行人”“玩家”“阁下”。
- 一句台词别超过三十来个字；想多说，拆成几句，中间夹个动作。

## 3. 名字与称谓

- 名字像真名：凡人多用小名、排行与俗名（秀兰、二牛、周老三、孙婆婆），修士与读过书的人用正经名字（沈青、林远舟、温如玉），不用四字拼凑（✗ 陆裂风岚、宁灵泉娘）。
- 平常提到一个人，多用“姓 + 身份”（周掌柜、韩猎户、秦道长），熟了再叫名字。

## 4. 句子

- 白话为主，带一点旧小说的腔调词即可（晌午、几文钱、后生、打尖），不堆“灵机”“天机”“大道”“道心”。
- 少用破折号；不用“不是……而是……”“既……又……”“一边……一边……”撑结构；四字词不连用三个以上。
- 句子长短错落。连着三句都一样长、一样的结构，就改一句。
- 同一类文字（物品、地点、事件开头）不要套同一个句式模板，读十条不能像一条改了几个字。险地别都用“进去的多、出来的少”暗示凶险，写一样看得见的痕迹。
- 人物的反应要分身份：道谢别都是“塞给你”，认可别都是“点点头”，拒绝别都是“摆摆手”。
- 文字说的要和实际得失对得上：说“搜走钱袋”就得真的全拿走，说“三天”就得真耗三天；不替没交代过的地点、身世、时长下断言。
- 数字只在得失与标签里出现；叙述里说“几块灵石”“小半袋”“一整天”，不说“获利 37”。人物报价、说年纪路程可以带数，用汉字写（“一株十二灵石”“今年三十七岁”“离这儿三天的路”）。
- 钱一律叫灵石，不写“文”“铜钱”“碎银”，免得玩家以为还有第二种钱。
- 会反复弹出的现编文字（拜访闲聊、茶馆传话）备几种说法轮换，同一种事在一段里只说一回。

## 5. 各类文字的写法

| 类别 | 写什么 | 不写什么 |
|---|---|---|
| 地点描述 | 一两个具体的景象或人事：谁在这儿、在干什么、有什么声音气味 | 功能与收益（适合闭关、资源丰富） |
| 物品描述 | 它从哪来、摸上去怎样、谁用它、怎么用 | 品阶、用途清单、“低阶”“起家材料” |
| 事件正文 | 眼前发生了什么，三四句，给出做选择需要的信息 | 心理描写的大段铺陈、形势分析 |
| 选项 | 玩家会怎么做，一个动作，十个字以内 | 结果预告（结果写在标签里） |
| 结果 | 事情怎么了结，一两句；得失交给标签 | 感想、教训、总结 |
| NPC 动态 | 像街坊传的话：“听说周掌柜把铺子盘出去了” | “人生进入中年阶段”“观望局势” |
| 纪事 | 发生了什么，一句话 | 形容词堆砌 |
| 界面提示 | 最短的必要信息，可以直接说机制 | 世界观铺陈 |

## 6. 自查

写完对照一遍：

1. 有没有“适合、擅长、提升、触发、资源、稀有、低阶、顶级、体系、机缘、门路”？叙述里有就改。
2. 有没有破折号、“不是……而是……”、结尾的感慨？
3. 念出来顺不顺？像不像这个人会说的话？
4. 十条同类文字，开头是不是都一个样？
